# Contracts

JSON Schema (draft 2020-12) definitions shared by all four machines. This directory is the integration surface.

| Schema | Written by | Read by |
|---|---|---|
| `company_profile` | dashboard (D) form / API client | A, B, C |
| `topic` | A | B, C, D |
| `source` | B | C, D |
| `finding` | B | A, C, D |
| `assumption` | C (D may set `user_override`) | C, D |
| `scenario` | C | D |
| `agent_event` | A (Cartographer) | D |
| `business_plan` | C | D |

## Rules
1. **Frozen after Phase 0.** After that, changes are **additive and optional only** (new optional fields, new enum values appended). Never rename, remove, or tighten.
2. Breaking change = new `schema_version` major, agreement from all four machines, and an ADR in `docs/adr/`.
3. Every object carries `schema_version` (`"1.0"`). Consumers must ignore unknown fields.
4. IDs are `<prefix>_<alnum>` (`t_`, `f_`, `s_`, `as_`, `sc_`, `a_`, `r_`, `rk_`), generated by the owner of the object.
5. Validate on **both** write and read at service boundaries (Ajv, see below).
6. Any change here needs a fixture added/updated in `/mocks` (by A, in the same PR; D owns all other fixtures) and a green `npm run validate`.

## Validate
```bash
npm run validate                       # every fixture in mocks/
node contracts/validate.mjs path.json  # specific files
```
Fixtures are named `<schema_name>.<variant>.json`; the first segment selects the schema. A file may hold one object or an array.

## Using schemas in code
```ts
import Ajv2020 from "ajv/dist/2020.js"
import addFormats from "ajv-formats"
import { readFileSync, readdirSync } from "node:fs"
// Register every *.schema.json under its file name (see contracts/validate.mjs), then:
const validateFinding = ajv.getSchema("finding.schema.json")!
```
Use `strictRequired: false` (see `validate.mjs` for why). Reject invalid objects with a readable message; when the writer is an LLM tool, return that message so the model can correct itself.

## Generating TypeScript types (optional)
```bash
npx json-schema-to-typescript -i contracts -o src/shared/types
```
Generated code is committed, never edited by hand.
